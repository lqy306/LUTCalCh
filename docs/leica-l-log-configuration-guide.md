# 徕卡 L-Log 配置与导入指南

本指南说明如何把随项目提供的徕卡 L-Log 配置导入 LutCalc 工作台，并说明配置包含的技术参数、适用范围和当前使用边界。参数均依据 Leica Camera 发布的《Leica L-Log Reference Manual v1.4》。[1]

## 配置文件

项目提供两份 JSON 配置，均符合 `lutcalc-log-gamma-profile` 第 1 版规范。

| 文件 | 适用机型 | 输入色域 | 数据范围 |
|---|---|---|---|
| `leica-l-log-v1.4-bt2020.json` | Leica SL2、SL2-S、Q3 | ITU-R BT.2020 | 完整范围，10 位 0–1023 |
| `leica-l-log-v1.4-bt709.json` | Leica SL（Typ 601） | ITU-R BT.709 | 完整范围，10 位 0–1023 |

两份配置使用相同的 L-Log 编码与解码公式。编码曲线以线性场景反射率为输入：当输入不大于 0.006 时，输出为 `8 × 输入 + 0.09`；其余区间为 `0.27 × log10(1.3 × 输入 + 0.0115) + 0.6`。解码公式是其分段反函数。[1]

> 使用 Leica SL（Typ 601）时，必须选择 BT.709 变体。Leica 明确说明，面向新机型的 L-Log LUT 并非为该机型的 BT.709 记录空间设计。[1]

## 导入步骤

先打开左侧的“曲线配置”区域，点击“导入配置”，然后选择上述 JSON 文件。通过校验后，配置会保存到当前浏览器；随后可在同一区域导出、删除或分享该配置文件。浏览器本地保存不会自动跨设备同步，因此需要跨设备使用时请导出 JSON 再导入。

配置中记录了完整范围、色域、白点、BT.2020 到 XYZ 的矩阵（BT.2020 变体）及 18% 中灰参考。L-Log 的 18% 反射率对应约 44% IRE；标准 L-Log LUT 工作流应先把中灰校准到该曝光位置。[1]

## 曝光与后期建议

如果目标是直接使用为 L-Log 设计的 LUT，请用灰卡和波形监视器将 18% 灰放在约 44% IRE。若采用 ETTR 方式获取更高动态范围和更干净阴影，需要先在后期进行曝光校正，再套用 LUT；否则可能出现色阶断层和画面平坦的问题。[1]

L-Log 是完整范围记录，不是视频电平。10 位素材应按 0–1023 解释，而不是按 64–940 解释，否则对比度与颜色判断会错误。[1]

## 当前接入边界

配置文件的导入、版本检查、保存、导出和分享已经可用。LutCalc 的原始 Gamma 计算内核仍需要一个受限公式解析器和曲线适配层，才能把配置中的 `encode` 与 `decode` 直接用于 LUT 生成。在适配层完成前，配置管理不会声称已经改变原始计算器的输出；这可以避免将公式字符串误当作可安全执行的脚本。

## 自制配置

个人开发者可以复制配置文件并修改 `id`、`name`、`curve`、`input` 和 `colorSpace`。拥有明确公式时使用 `formula`；只有测量点或白皮书表格时使用 `samples`。每个采样点必须在 0 到 1 范围内，并至少提供两个点。不要把任意 JavaScript 放入公式字段；公式只应表达受限的数学运算。
