- **Theme Name**：胶片实验室

# 选定方向：胶片实验室

## Design Movement

选择 **新粗野主义编辑设计（editorial neo-brutalism）** 与现代色彩科学工具的结合。保留 LutCalc 原本偏工程化的工具气质，但将分散、密集的控件整理成“工作台—参数卡—输出条”的清晰阅读路径。

## Core Principles

1. **先看信号，再调参数**：输入、工作空间、输出和预览必须形成明确的视觉顺序。
2. **编辑感而非装饰感**：使用标签、规则线、编号、色块和等宽数字制造专业记录感，不依赖大面积渐变或统一圆角卡片。
3. **密度可控**：默认展示关键参数，高级选项通过折叠与分组进入，保持信息丰富但不压迫。
4. **每个动作有反馈**：选择、滑杆、重置、下载和预览都应有即时而克制的视觉回应。

## Color Philosophy

底色采用偏暖的纸张灰，借鉴未漂白的印相纸与实验记录本；主文本使用深墨黑而不是纯黑，减少长时间使用的疲劳。品牌强调色选择 **硫磺黄（#E3F24F）**，像暗房中的校准标记，用于当前状态、关键 CTA 与信号高亮；蓝绿色仅作为色彩空间与预览状态的辅助标识，避免把界面做成普通蓝色后台。

## Layout Paradigm

采用不对称的三段工作流：左侧为窄幅“项目轨道”与输入/输出概览，中部为主要参数工作台，右侧为可折叠的预览与输出检查。桌面端强调横向工作面，移动端则将轨道转为顶部步骤条、将右侧预览下沉到参数之后，避免简单地把桌面三栏压缩成拥挤单栏。

## Signature Elements

- **校准条**：页面顶部与关键区块使用细的硫磺黄刻度线，代表信号校准。
- **胶片标签**：每个模块有小型编号标签（01 / 02 / 03），像胶片盒与实验记录的索引。
- **信号色块**：预览区域用小型 RGB/亮度条与色域提示强化 LUT 的视觉主题。

## Interaction Philosophy

交互应像操作一台精密但可理解的仪器。下拉选择突出当前值与辅助说明；滑杆旁显示可复制的数值；重置动作只影响当前分组并给出轻量提示；下载按钮在配置完整时呈现明确的“ready”状态，而不是始终高亮。

## Animation

仅使用 120–220ms 的 opacity 与 transform 过渡。面板首次进入时以轻微上移和淡入出现，参数分组按 40ms 节奏错开；滑杆不做弹跳动画，避免影响精调；折叠区用高度过渡时保持内容稳定。任何核心操作都应尊重 `prefers-reduced-motion`。

## Typography System

标题使用 **Space Grotesk**，用于品牌名、区块标题与大号数值，形成现代但不冷漠的工具感；正文使用 **DM Sans**，保证说明文字与表单标签的可读性；参数值和元数据使用 **IBM Plex Mono**，强调精确、可扫描与可复制。层级规则：页面标题 34/40，区块标题 16/22，标签 11/14 大写加字距，正文 13/20，数值 14/18 等宽。

## Brand Essence

**LUTCalc 是给影像创作者使用的浏览器内 LUT 工作台：保留专业色彩转换能力，同时让每一次校准都更容易读懂、检查和导出。**

人格关键词：**精确、克制、可亲近**。

## Brand Voice

标题、CTA 和微文案像一位经验丰富的调色师在旁边提示，而不是堆砌营销话术。避免“欢迎使用”“立即开始”等泛化表达。

示例：

- 标题：**把输入信号整理成可控的画面。**
- CTA：**生成并下载 LUT**

## Wordmark & Logo

标志使用一个由三条不同长度的水平色带组成的抽象“L”形校准符号：左侧短条代表输入，中央长条代表工作空间，右侧上扬短条代表输出。标志不包含文字，使用硫磺黄和深墨黑双色，在顶部导航与 favicon 中保持清晰识别。

## Signature Brand Color

**硫磺黄 `#E3F24F`**：这是品牌唯一的强识别色，承担“当前、校准、可执行”的语义，而不是作为装饰性点缀泛滥使用。
