# LUTCalc 原版布局回归基准

## 用户提供的调整项截图

原版调整项不是独立的浮动卡片网格，而是一个连续的纵向区域。标题行从左至右依次为红色编号块“04”、标题“调整项”、说明文字；右侧是带红色勾选框的“启用调整项”总开关。模块条目紧贴标题区下方，以整行边框和细分隔线排列。

启用的白平衡条目使用深红色半透明表面和红色边框，左侧为红色勾选框与“白平衡”，右侧为“已启用”。条目展开内容直接位于该行下方，不另起独立卡片；内容区域保持同一连续容器，并使用左对齐的说明文本与状态文本。

## 用户提供的白平衡截图

白平衡内部控件保持原版的紧凑纵向排列：顶部是“White Balance”复选框；下面依次是“Reference White”数字输入、“New White Balance”数字输入和“Unlock Lightsource From New White”按钮。其后是两个水平滑块分组：第一组从 CTO 到 CTB，中间显示 Clear 与 Reset；第二组从 Minus Green 到 Plus Green，中间显示 Clear 与 Reset。滑块容器使用浅灰色实体表面、细边框和轻微圆角。

## 本轮布局回归要求

主工作台整体应从当前“现代参数卡工作台”回归原版 LUTCalc 的密集纵向布局：减少卡片间距和大面积留白；保留原版模块顺序、标题层级、整行条带、控件密度和展开关系；不再将原版布局差异仅通过颜色或圆角装饰处理。默认加载时“启用调整项”应为选中状态，白平衡等子调整项的默认启用/展开状态应继续与原版一致。
