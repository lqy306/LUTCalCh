# LUTCalc 原版与当前中文工作台界面对照

## 原版的核心规律

原版不是把所有内容做成卡片，而是采用一个几乎无装饰的固定工作区。顶部只有一条蓝色标题栏；主体从左到右分为两列，左列宽度约 42%，右列约 58%。左列依次放置 Camera、Gamma/Gamut、Customisation；右列依次放置 LUT 输出、操作按钮、Instructions/Tables/Charts/Print Chart、曲线与数据表。整体背景为浅灰，模块采用细灰边框，控件高度约 18–22px，标签与控件水平对齐，模块之间的空白很少。

原版的视觉层级主要靠**位置、细边框、灰色条和蓝色标题栏**建立，而不是靠大字号标题、彩色卡片、圆角、阴影或编号。左侧是“输入与调整”，右侧是“输出与验证”，用户的阅读路径非常稳定：先选相机和输入管线，再选输出格式，最后直接看曲线和表格。

原版把最关键的动作按钮放在输出区域和曲线区域之间，按钮文字短、尺寸小、排列连续。曲线不是独立的大型卡片，而是右栏中的一个诊断面板；曲线下方直接显示 Reflected%、LUTted %IRE、10-bit Values，形成即时反馈闭环。

## 当前版本的问题

当前版本虽然已重排成双栏，但仍保留了现代工作台的很多结构：左侧额外存在一个约 190px 的“工具中心”侧栏；顶部有深色应用栏、主计算器大标题和“引擎已连接”状态；每个区域使用 01–05 编号、较大的模块标题、说明副标题和独立卡片。结果是主计算器真正可用的横向宽度被压缩，原版的两列比例被三栏框架打断。

当前版本的输出区、预览区和调整区虽然位置接近原版，但仍有多个层级同时竞争：大卡片标题、中文说明、编号色块、输出选项容器、导出反馈条和预览工具栏。尤其在截图中，输出卡片内部控件已经非常紧凑，但外部卡片标题和边距没有同步减小，因此出现“外框像现代仪表盘，内部像旧式工具”的混合感。

当前版本的相机输入和色彩管线被拆成两个独立大卡片，并放在右栏输出上方/下方的网格中；这使输入路径不如原版的左列连续。原版的相机、Rec Gamma/Gamut、Out Gamma/Gamut 在同一左列连续排列，输出区则完全属于右列，分工明确。

当前版本把“原版预览与曲线”做成独立的大卡片，并保留了较大的预览区域，但没有把原版的 Instructions/Tables/Charts/Print Chart 和曲线数据表完整放在同一诊断区域内，因此右栏的专业反馈密度仍低于原版。

## 应采用的重构方向

第一，应把工具中心从默认主布局中移出，改成可关闭的抽屉或窄按钮；主计算器应恢复真正的两栏画布。第二，应取消主计算器内部的 01–05 大编号和长副标题，保留中文标签，但改用原版式的短分区标题和细灰分隔线。第三，应严格采用“左列输入与调整、右列输出与诊断”的信息架构，不再把色彩管线作为独立的横向大卡片。第四，应将曲线、表格、预览按钮和诊断数据组合成一个右栏诊断面板，而不是只展示一张曲线图。第五，应统一控件尺寸、标签基线和间距，优先保证一屏看到完整的 Camera、Gamma/Gamut、LUT 输出、Generate、曲线与关键数值。

## 结论

当前版本的问题不是“还不够紧凑”，而是**只压缩了控件，却没有复刻原版的信息架构和视觉语法**。下一步不应继续增加 CSS 覆盖，而应简化主界面 DOM 层级：减少外壳、减少重复说明、收窄工具中心、恢复两列连续面板，并将诊断信息前置到右栏核心区域。

## 2026-08-21 最新布局验证

最新本地截图显示，相机输入卡片不再被右侧输出卡片的高度拉伸，色彩管线紧接其后；调整项已回到左栏并压缩为单列窄面板，右侧预览跨越色彩管线和调整项两行，主区域形成更完整的矩形。当前仍保留左侧工具中心侧栏，后续可根据需要继续收窄或默认折叠，但核心参数区的内部空白已经明显减少。

最新布局截图中，相机输入卡片与色彩管线已无大块间隔；调整项面板已收窄为左栏窄面板，右侧预览保持完整高度。

## 功能回归记录（续）

ARRI 相机品牌切换通过，型号、原生 ISO、记录 Gamma/Gamut 和曲线同步变化。输出维度单选状态读取到 3D 已选中，17³ 网格选项也保持有效。启用 WFM 后，预览区域出现黑色波形监看区域，说明诊断叠加开关仍然工作。随后在 ARRI 管线下点击“生成 LUT”，页面显示可读文件名和“最近一次导出已触发”反馈，导出动作桥接正常。

生成套装入口已触发，页面保持稳定并显示最近一次导出反馈。调整项总开关与单项开关均可点击，窄面板在启用/停用状态下没有布局溢出；启用 WFM 后的预览也保持正常。亮色/深色主题切换通过，深色主题下输入控件、窄调整面板和波形区域均能跟随主题更新，之后已恢复亮色。

流程回归通过：点击“开始记录”后顶栏状态变为“正在记录参数操作”，修改 LUT 格式后步数从 0 增至 1，点击“停止记录”后状态恢复并保留 1 步。工作流的核心状态切换和参数捕获正常。

## 最新视觉诊断

直接查看无标注截图后确认：调整项每行之前确实过高，压缩后已经变成短条；但当前版本仍把调整项放在左栏，且右侧曲线区域结束后主工作区下方还有明显空白。用户原意应是将调整项放入右栏输出与曲线之间的空位，而不是放回左栏。下一版应改为右栏三段连续结构：LUT 输出 → 窄调整项 → 曲线预览；左栏只保留相机输入和色彩管线，并让左栏面板自然堆叠，避免由右栏网格轨道制造空洞。

## 右栏三段式截图结论

最新清洁截图确认右栏已经形成“LUT 输出 → 调整项 → 原版预览与曲线”的连续结构，调整项每行已明显矮化，长摘要也已隐藏，整体比此前清爽很多。剩余主要问题是左栏只有相机输入和色彩管线，两块内容总高度明显低于右栏三段内容，因此左下方出现大片同色空区。这个空区不是卡片内部拉伸，而是两列内容高度不对称造成的工作区留白；后续应通过给左栏增加轻量的连续背景/摘要区域，或重新平衡右栏三块高度来处理，而不是再把相机卡片拉高。
