# LUTCalc 类中文计算器：从零设计蓝本

## 使用方式

这是一份供另一个 AI 从零设计和实现 LUTCalc 类 Web 应用的任务蓝本。请不要把当前项目代码、构建产物或现有组件直接复制过去；应以本文件定义的产品目标、交互结构、视觉基准和用户独家资源为依据重新设计。

原版功能参考页面：

- [LUTCalc 原版页面](https://cameramanben.github.io/LUTCalc/LUTCalc/index.html)

原版计算核心遵循其原有开源许可证。实现前应自行阅读源码、确认许可证、确认计算入口，并在新项目中保留相应版权和许可证说明。

## 1. 产品定位

设计一个面向摄影师、调色师和电影制作人员的中文 LUT 计算工作台。它不是普通表单，也不是营销型网站，而是一个高密度、可持续操作、以参数关系和曲线反馈为核心的专业工具。

产品必须同时满足三点：

1. **计算逻辑可靠**：相机输入、记录伽马、色域、输出伽马、输出色域和 LUT 生成必须形成连续的计算链路。
2. **操作结构接近原版 LUTCalc**：尤其是 01/02/03/04/05 模块顺序、调整项连续列表、白平衡展开区和 LUT 解析位置。
3. **界面完全中文化且可主题化**：中文是主语言，行业标准名称如 S-Log3、V-Log、ARRI Wide Gamut、`.cube` 可以保留。

## 2. 设计方向

总体方向不是“现代 SaaS 仪表盘”，也不是充满大圆角、渐变、玻璃拟态和紫色霓虹的通用 AI 界面。

设计应参考 LUTCalc 原版的专业工具感：

- 密集但清晰；
- 低圆角或近似直角；
- 细边框和连续横向条带；
- 章节编号明确；
- 标题、说明、控件和状态信息层级清楚；
- 减少不必要的留白；
- 让用户能够在一个视口中看到尽可能多的相关参数。

默认视觉主题可以参考 Ubuntu：深紫色顶部栏、Ubuntu 橙强调色、浅灰工作区、白色参数面板、低圆角和 Ubuntu 字体。主题系统必须允许后续切换为 KDE、macOS、Omarchy、Leica 固件和 Lumix 固件风格。

## 3. 主布局蓝本

桌面端按以下顺序排列：

```text
顶部标题栏

01 相机输入                 02 色彩管线

03 LUT 输出（占满主工作区）

04 调整项（占满主工作区，连续纵向列表）

05 曲线预览（占满主工作区，白色背景）
```

### 01 相机输入

包含：

- 相机品牌；
- 相机型号；
- 原生 ISO；
- CineEI ISO；
- 挡位修正。

### 02 色彩管线

分成两个紧凑的子区域：

- 记录设置：伽马品牌、记录伽马、色域品牌、记录色域；
- 输出设置：伽马品牌、输出伽马、色域品牌、输出色域。

### 03 LUT 输出

全宽显示，包含：

- LUT 标题 / 文件名；
- 输出格式；
- 硬裁切；
- 更新预览；
- 生成 LUT；
- 生成套装。

字段和操作按钮应在同一块紧凑区域内排列，不要拆成侧栏或弹窗。

### 04 调整项

调整项是整个界面的关键部分。必须参考用户提供的原版截图，不要改成四列网格，也不要让每个调整项成为独立悬浮卡片。

标题行包括：

- 左侧红色编号块“04”；
- 标题“调整项”；
- 说明“按原版层级组织校正模块；LUT 解析位于列表末尾。”；
- 右侧带勾选框的“启用调整项”总开关。

总开关默认启用。常规子调整项默认显示为已启用。每个子项都使用连续横向条带：左侧是选择框和名称，右侧是“已启用 / 未启用”。打开后，参数区直接出现在该条目下方。

调整项顺序：

1. 白平衡；
2. PSST-CDL；
3. ASC-CDL；
4. 多色调；
5. 高光色域；
6. 膝点；
7. 黑电平 / 高光电平；
8. 黑伽马；
9. 显示色彩空间转换；
10. 色域限制；
11. 伪色；
12. LUT 解析。

LUT 解析必须是最后一个同级条目，不得放回侧边栏。

### 05 曲线预览

曲线预览占满主工作区，始终使用不透明白色背景。无论主题是浅色还是深色，都不能让曲线区域跟随主题变成深色，也不能使用会使曲线消失的混合模式。

## 4. 白平衡布局基准

白平衡默认启用并展开。内部布局应参考用户提供的截图：

```text
白平衡

参考白                         5500 K
新白平衡                       5500 K

        从新白平衡解锁光源

[水平滑块]                 CTO -------- CTB
                 清除       重置

[水平滑块]        Minus Green -------- Plus Green
                 清除       重置
```

输入区使用紧凑的数字输入。滑块使用浅灰色实体容器，滑块横向铺开，两端显示方向标签，中间放清除和重置按钮。不要把这些控件改成普通的现代 Toggle、圆角卡片或纵向长表单。

## 5. LUT 解析交互

LUT 解析必须属于调整项列表，包含：

- 导入新 LUT / 读取已分析 LUT；
- 文件选择；
- 当前文件名；
- 分析 LUT；
- 重置。

分析完成后必须更新：

- 输出伽马或分析结果；
- LUT 标题；
- 曲线预览。

实现时不能只监听文件输入的 `change` 事件，因为原版分析通常包含异步处理。应通过同源原型桥接、完成消息或可靠状态轮询确认分析结束。

## 6. 核心功能范围

必须实现或保留以下能力：

- 相机品牌和型号选择；
- 原生 ISO、CineEI ISO、挡位修正；
- 记录伽马、记录色域、输出伽马、输出色域；
- LUT 标题和文件名；
- LUT 输出格式；
- 硬裁切；
- 预览刷新；
- LUT 生成和套装生成；
- 调整项总开关与各子项开关；
- 白平衡、CDL、伽马、色域和限制器调整区域；
- LUT 文件解析；
- 实时曲线预览；
- 明暗模式；
- 内置主题切换；
- 可选的工作流程录制、导入、导出和回放；
- 可选的 Log / Gamma 外部配置文件机制。

## 7. 主题系统

主题必须是标准 JSON 配置，而不是散落在组件中的硬编码颜色。每个主题至少定义：

- 主题 ID 和名称；
- 字体栈；
- 明色模式颜色；
- 暗色模式颜色；
- 画布颜色；
- 面板颜色；
- 卡片颜色；
- 文字和弱文字；
- 边框；
- 强调色；
- 顶部栏；
- 控件背景；
- 圆角；
- 阴影。

内置主题方向：

| 主题 | 设计关键词 |
|---|---|
| Ubuntu | Ubuntu 字体、深紫顶部栏、Ubuntu 橙、工具型桌面 |
| KDE | Plasma 工具感、蓝色强调、紧凑面板 |
| macOS | 克制的灰白层级、细边框、简洁控件 |
| Omarchy | 开发者工作台、硬朗分区、深色高对比 |
| Leica 固件 | 黑色、白色、红色强调、LG1056 字体、相机固件感 |
| Lumix 固件 | 深色摄影设备 UI、橙色或红色状态强调、紧凑信息层级 |

## 8. 用户独家资源使用规则

本蓝本附带的独家资源只用于新项目的视觉和配置参考，不应被网上搜索到的替代资源覆盖。

### Leica LG1056 字体

资源文件：`exclusive-resources/fonts/lg1056_regular.otf`

使用要求：

1. 作为网页字体加载，而不是只填写字体名称。
2. Leica 主题的标题、关键标签或固件式控件可以使用该字体。
3. 不要把该字体扩散到所有主题。
4. 不要上传到公共字体库或替换成网上下载的相似字体。
5. 发布前请自行确认字体授权范围。

### 用户提供的参考截图

`exclusive-resources/references/` 下的截图用于确定布局、白平衡控件顺序和调整项层级。它们不是网络素材，而是设计基准。

### 独立 L-Log 配置

如果使用本资源包中的 L-Log JSON，它应作为独立配置文件参考，不要无提示地把它硬编码进主程序。主程序是否内置 L-Log 必须由产品所有者明确决定。

## 9. 技术建议

可以使用 React、Vue、Svelte 或其他现代前端框架，但必须保持以下边界：

- 可见界面由原生前端组件实现；
- 原版计算核心与新界面之间有清晰桥接层；
- 不显示第二套旧版界面；
- 不通过大量 CSS 补丁修补旧版可见 UI；
- 所有关键操作都要有成功、失败和异步状态；
- 不将核心逻辑写在渲染阶段；
- 主题令牌集中维护；
- 支持桌面端和移动端。

## 10. 验收标准

### 布局

- 01/02 为同一行双栏；
- 03/04/05 各自全宽；
- 调整项是连续纵向条带；
- LUT 解析位于调整项末尾；
- 白平衡展开后不产生错位、横向溢出或隐藏按钮；
- 移动端可滚动，所有控件可操作。

### 默认状态

- 总调整项开关默认勾选；
- 常规调整项默认已启用；
- 白平衡默认展开；
- 曲线预览始终白底。

### 功能

- 参数修改会影响引擎；
- 预览会刷新；
- LUT 分析会真正改变分析结果和曲线；
- LUT 可以生成和导出；
- 主题和明暗模式可切换；
- 主题状态可以持久化。

### 视觉

- 不使用默认 Inter 作为唯一字体；
- 不使用紫色渐变、玻璃拟态、过多圆角或营销页式留白；
- 不出现 iframe 套娃；
- 不出现主界面与旧版界面两套标题栏或重复控件。
